The user wants a short, direct answer to the question below. Nothing more.

## Input
$ARGUMENTS

## How to answer
- Answer the question directly in the first sentence.
- 2-3 lines total. If you're writing a fourth, stop.
- For yes/no questions, lead with **Yes** or **No**, then at most one clause of justification.
- Apply the plain-language voice from `/say`: active, direct, no filler.
- REMOVE ALL JARGON

## Hard rules
- **No next steps.** Don't offer to do anything, fix anything, or investigate further.
- **No extra context.** Don't explain caveats, edge cases, or related facts the user didn't ask about.
- **No preamble.** Don't restate the question or say "Great question."
- If you genuinely can't answer, say so in one line and ask one short clarifying question — nothing else.
